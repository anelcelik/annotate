## Screen Annotator Pro 6.1.0 — about 90 MB smaller

### Changed
- **A much smaller app.** The video engine inside the app (ffmpeg) is now built for Screen Annotator Pro alone, with only the parts it actually uses:
  - **13 MB instead of 105 MB**, so the installed app is about 90 MB smaller, and the download shrinks with it.
  - Recording (normal and graphics chip), GIF / WebM / MP4 export, trimming, the PC's sound and the webcam bubble all work exactly as before.
  - Every build is checked automatically to contain everything the app calls.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. |
| `ScreenAnnotatorPro-Portable.exe` | One file, no install. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
