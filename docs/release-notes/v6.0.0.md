## Screen Annotator Pro 6.0.0 — recording on the graphics chip, now on any screen and with pause

### New
- **Graphics-chip recording works on any screen.** With *Settings → Recording → Record with the graphics chip (beta)* on, it now handles:
  - the monitor in use, whichever one that is;
  - an area or a window on any monitor;
  - laptops whose external screen hangs off the second graphics chip.

  Only "All monitors" on a multi-screen setup still uses the normal recorder, since one graphics-chip capture covers one screen.
- **Pause works on the graphics chip too.** Each pause closes a piece of the recording, and stopping joins the pieces into one file. The picture is copied, not re-encoded, so it takes a moment and loses nothing.

### Smaller download
- One Qt file the app never uses is no longer bundled.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. |
| `ScreenAnnotatorPro-Portable.exe` | One file, no install. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
