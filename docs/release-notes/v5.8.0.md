## Screen Annotator Pro 5.8.0 — pen pressure, trim your recordings, record one window

### New
- **Pen pressure.** With a Surface Pen, a Wacom or any Windows Ink pen, strokes get thicker the harder you press. See-through strokes stay smooth. With a mouse, nothing changes.
- **The pen's eraser end erases.** Flip the pen over and rub out marks, then flip it back to carry on with the tool you had. Touch screens draw with a finger, the same as a mouse.
- **Trim a recording.** *Recording saved → Trim…* shows the video with a timeline.
  - Drag the two handles to where it should start and end. The picture shows the frame at the handle you move. **←** / **→** fine-tune by a tenth of a second, or a whole second with **Shift**.
  - *Save trimmed copy* writes `…-trimmed.mp4` next to the recording. The original stays as it was.
- **Record one window.** Settings → Recording → **Pick a window**. When you press Record, click the window you want: it comes to the front and its area is recorded, after the 3-2-1 countdown.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. |
| `ScreenAnnotatorPro-Portable.exe` | One file, no install. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
