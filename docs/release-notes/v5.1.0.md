## Screen Annotator Pro 5.1.0 — fixes that matter, and a lighter app

### Fixed
- Annotations now land exactly where you drew them in **screenshots and recordings at 125 % and 150 % display scaling** (they were scaled twice).
- **Recording with the microphone works again** — current ffmpeg lists microphones differently and none was ever found; the app now picks your microphone automatically.
- The **eraser** no longer leaves black streaks in recordings and holes in screenshots, and on Windows erased areas no longer let clicks fall through the overlay.
- **Blur** fully covers what it hides, right up to the edge, and picks the right area when a monitor sits left of or above the main one.
- **Start with Windows** really starts the app when you sign in (the Store package now uses a startup task).
- **Shortcuts:** new defaults that don't clash with your browser — **Ctrl+Alt+R** to record (was Ctrl+Shift+R, hard reload), **Ctrl+Alt+T** for Snip & Read (was Ctrl+T, new tab). One unsupported key used to switch off every shortcut; a single letter could be set as a global shortcut; Ctrl+Shift+R fired twice in drawing mode. All fixed, and if another app already owns a shortcut the app now tells you.
- Numbered callouts keep counting correctly after an undo.
- Dark mode now applies to every window.
- Snip & Read is hidden in builds that don't include the OCR engine (the Store package) instead of showing an error.

### Improved
- **Clear all, deleting and moving a shape can be undone** — Clear shows an Undo button.
- A deleted recording goes to the **Recycle Bin**, and Delete sits away from Close.
- Exit **asks first** when marks would be lost, and **finishes saving a running recording** before quitting.
- Settings has a **Shortcuts** tab that shows clashes and taken shortcuts, can clear a shortcut, and resets to defaults. Every tab now fits its own content.
- The Store review prompt only appears right after something worked (a screenshot or recording saved), never on a timer, and uses the Store's in-app rating dialog.
- **Smaller and lighter:** about 35 % less to install (unused libraries and a smaller, pinned ffmpeg 9.0.2), and the overlay releases its memory while it isn't needed.
- Open-source licenses are listed under Settings → Licenses.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. No Snip & Read. |
| `ScreenAnnotatorProVideo-Lite.exe` | One portable file, no install. No Snip & Read. |
| `ScreenAnnotatorProVideo.exe` | Portable, with Snip & Read (OCR + translate) — large, slower to start. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
