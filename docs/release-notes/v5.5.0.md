## Screen Annotator Pro 5.5.0 — change marks after you draw them, show your shortcuts, hover hints

### New
- **Edit what you've drawn.** With **Select** (**V**), click a mark to select it:
  - drag it to move it, or drag its white handles to reshape it (an arrow's tip, a box's corner);
  - the dock shows *Selected arrow* (or box, text…) with its colour, stroke and opacity, and changing them restyles the mark on the spot;
  - drag across empty space to frame several marks, or **Shift**-click to add and remove them;
  - move, restyle or delete all selected marks at once;
  - **Ctrl+C / Ctrl+V** copy and paste, **Ctrl+D** duplicates, **Ctrl+A** selects everything, and the arrow keys nudge (**Shift** for 10 px).

  All of it can be undone, and a slider drag counts as one undo step.
- **Show pressed shortcuts on screen.** A pill near the bottom of the screen shows the shortcut you just pressed, like *Ctrl + Shift + Z* or *F5*, so viewers and recordings can follow along. It only shows shortcuts and special keys (Ctrl/Alt/Win combinations, F-keys, Enter, Esc, arrows…). Plain typing never appears, so a password typed while recording stays private. Turn it on in **Settings → General** or on the dock's **Presenter** menu. Off by default.
- **Hover hints everywhere.** Hover a dock button to see what it does and its key. The hints now also work in click-through mode and while another window has focus. Don't need them any more? Turn them off in **Settings → General → Show a hint when hovering over a button**.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. |
| `ScreenAnnotatorPro-Portable.exe` | One file, no install. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
