## Screen Annotator Pro 6.2.0 — hide private info in one key, paste recordings anywhere, and a full guide

### New
- **Find private info (B).** Press **B**, or *Find private info* on the Blur, Pixelate or Black box tool. The screen under your cursor is read, and everything private on it is hidden at once:
  - email addresses and phone numbers;
  - card numbers and IBANs — only when their checksum is right, so order numbers and dates stay readable;
  - API keys and tokens;
  - whatever follows "Password:", "PIN:" or "Token:".

  It uses the redaction you have in hand: blur, unless Pixelate or Black box is chosen. The results are ordinary marks, so you can move them, and one **Ctrl+Z** brings everything back. Reading happens on your PC with Windows' own text recognition; nothing leaves it.
- **Copy a recording.** *Recording saved → Copy* puts the video file on the clipboard. Press **Ctrl+V** in Teams, Slack, Discord, an email or a folder to paste it. A GIF, WebM or trimmed copy can be copied the same way when it's done.

- **The Guide.** *Settings → ⓘ Guide*, or **F1** anywhere: every feature explained step by step.
  - Topics: getting started, drawing, editing, presenting, privacy, capture, recording, pen, shortcuts, settings, and fixes for common problems.
  - A search box finds any of it as you type.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. |
| `ScreenAnnotatorPro-Portable.exe` | One file, no install. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
