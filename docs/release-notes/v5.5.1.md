## Screen Annotator Pro 5.5.1 — a real magnifier, and two fixes

### New
- **Magnifier, Greenshot-style.** **M** (or the magnifier on the dock) now opens a round loupe beside the cursor instead of zooming the whole screen:
  - a crosshair marks the exact pixel under the cursor;
  - from 4× up you see real, sharp pixels;
  - the mouse wheel zooms from 2× to 16×;
  - the loupe flips sides at the screen edges;
  - **Esc**, **M** or a right-click closes it.

  It shows a snapshot taken the moment you press M, with your annotations in it.

### Fixed
- Hover hints showed as an empty black box, in both light and dark mode. They now appear as a readable card in the app's theme.
- Callouts, steps (the 1 2 3 markers) and the ruler were drawn at whatever opacity another tool had been left at. They have no opacity control, so they are always drawn solid now.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. |
| `ScreenAnnotatorPro-Portable.exe` | One file, no install. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
