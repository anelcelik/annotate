## Screen Annotator Pro 5.4.0 — zoom, a friendlier whiteboard, and recording on the graphics chip (beta)

### New
- **Whiteboard, friendlier:** **W** (or the board button) now simply opens and closes the board, and **Settings → General → Whiteboard style** picks white or dark. The dock comes onto the board with you — expanded if it was tucked away — and goes back where it was when you leave.
- **Recording on the graphics chip — beta, opt in.** Settings → Recording → *Record with the graphics chip (beta)*. On a single screen, the screen is captured and encoded by your PC's graphics chip — the one built into every Windows laptop (Intel, AMD, NVIDIA) — instead of the processor: far less CPU, heat, fan noise and battery, smooth 4K, and a responsive dock while you record. If a PC can't do it, recording switches to the normal recorder by itself. Off by default until it has been tried on more machines; no pause in this mode yet, and multi-monitor setups use the normal recorder.
- **Zoom.** Press **M** (or the magnifier on the dock) to magnify the screen you're on around the cursor, annotations included. The mouse wheel zooms from 1.25× to 8×, the view follows the cursor, and **Esc**, **M** or a right-click leaves. Zoom shows in recordings too, and you can give it a global shortcut in Settings → Shortcuts.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. |
| `ScreenAnnotatorPro-Portable.exe` | One file, no install. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
