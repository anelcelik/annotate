## Screen Annotator Pro 5.9.0 — record the PC's sound, and a webcam bubble

### New
- **Record what the PC plays.** Settings → Recording → **Record the PC's sound**. A video, a call, the app you're demoing: whatever comes out of your speakers goes into the recording.
  - With the microphone on too, both are mixed together.
  - Quiet stretches stay in step with the picture, and pausing the recording pauses the sound as well.
  - The sound is added when you stop, which takes a second or two before the recording panel appears. If that ever fails, the recording is still saved, just without the PC's sound.
- **Webcam bubble.** Dock → **Presenter** → *Webcam bubble* puts your camera in a circle on top of everything.
  - It's a real window on screen, so it's in your recordings and on a shared screen.
  - Drag it anywhere. The mouse wheel sizes it.
  - Right-click it to mirror it, switch to a rounded square, or close it.
  - Pick the camera in Settings → Recording. The bubble remembers where you left it.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. |
| `ScreenAnnotatorPro-Portable.exe` | One file, no install. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
