## Screen Annotator Pro 5.3.0 — for presenters

### New
- **Whiteboard and blackboard.** Press **W** (or the board button on the dock) for a whiteboard over the screen you're on, **W** again for a blackboard, again to close. **PgDn / PgUp** add and switch pages, each with its own undo. Your desktop annotations wait aside and come back when you leave — **Esc** leaves the board.
- **Spotlight.** Press **F** (or Presenter → Spotlight): everything but the area around your cursor is dimmed. The mouse wheel sizes it.
- **Cursor halo and click ripples** (Presenter menu): a highlight around the cursor and a ripple on every click — they work while you're clicking through to the app underneath, and they show up in recordings. Perfect for tutorials.
- **Fading ink.** Switch **FADE** on for the pen, lines, arrows and shapes and your marks disappear by themselves after a few seconds — draw, explain, carry on. Blur, pixelate and black boxes never fade, so nothing you hid gets revealed.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. |
| `ScreenAnnotatorPro-Portable.exe` | One file, no install. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
