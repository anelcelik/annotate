## Screen Annotator Pro 5.2.0 — Snip & Read is back, and drawing got easier

### New
- **Snip & Read everywhere, including the Store version.** It now uses the text recognition built into Windows: offline, instant, nothing to download, and it reads every language you have installed in Windows (it used to be English only). Fix a misread letter right in the result, copy it, or send it to **Google Translate** in one click.
- **Screenshot an area.** Capture now lets you drag an area, click for a whole screen, or press Enter for all screens — with your marks in the picture. It has its own shortcut (**Ctrl+PrtSc**), and Save starts in your *Screenshots* folder and then remembers where you saved last.
- **Type text where you click.** No more dialog on another monitor: labels are typed right on the screen, over several lines (Shift+Enter), with an optional **background box** that keeps them readable on busy screens. Click a label to edit it.
- **An eraser that removes whole marks** with one touch — one undo step per drag. The rub-out eraser is still there under *Pixels*.
- **Pixelate is real now**: large blocks of what's actually underneath instead of grey noise, never smaller than 10 px so text can't be read back.
- A three-step welcome for first-time users.

### Improved
- Selecting picks the mark under your pointer — a long diagonal arrow no longer grabs every click in its bounding box.
- Callouts and steps follow the **Size** slider (they were tiny on 4K).
- The ruler measures in **real screen pixels** — at 125 % a 100-point line reads 125 px, matching your screenshots.
- Changing the dock size in Settings applies immediately.
- Drawing, the laser pointer and the eraser only repaint what changed: **about 20× less work per mouse move** on large or multiple screens (measured on 2 × 4K with 100 marks: 32.6 ms → 1.6 ms).
- See-through arrows and rulers are evenly transparent (from 5.1.1).
- One portable `.exe` instead of two: with Windows doing the OCR, the 307 MB "full" build is no longer needed.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. |
| `ScreenAnnotatorPro-Portable.exe` | One file, no install. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

All of them include Snip & Read. The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
