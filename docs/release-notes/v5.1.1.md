## Screen Annotator Pro 5.1.1

### Fixed
- **See-through arrows** looked broken: the shaft showed through the head and the head had a darker ring, because the shaft, the head and its outline were blended on top of each other. An arrow is now one shape, painted once, so it is evenly transparent at every opacity. Fully opaque arrows look exactly as before.
- The same for the **ruler**: no more dark blobs where the end ticks cross the line when the colour is see-through.

Everything in [5.1.0](https://github.com/anelcelik/annotate/releases/tag/v5.1.0) is included.

### Which file do I want?
| File | What it is |
|---|---|
| `ScreenAnnotatorPro-Setup.msi` | Classic installer: Program Files, Start menu, optional desktop shortcut. No Snip & Read. |
| `ScreenAnnotatorProVideo-Lite.exe` | One portable file, no install. No Snip & Read. |
| `ScreenAnnotatorProVideo.exe` | Portable, with Snip & Read (OCR + translate) — large, slower to start. |
| `ScreenAnnotatorProVideo.msix` + `.cer` | Sideload test build of the Store package — see `INSTALL-MSIX.txt`. Conflicts with a Store install. |
| `ScreenAnnotatorPro-StoreSubmission.msix` | Unsigned, for Partner Center only — not for installing. |

The .exe and .msi builds are not code-signed, so Windows SmartScreen asks once: *More info → Run anyway*.
