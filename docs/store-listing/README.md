# Store listing in other languages

Translations of the English listing in [`../infosMS.md`](../infosMS.md)
(5.2 copy). In Partner Center: **Store listings → Manage additional
languages**, add the language, then paste each section into its field.
A listing language doesn't have to be one the app's interface supports.

| File | Language | Partner Center code |
|---|---|---|
| [de.md](de.md) | German | de-de |
| [fr.md](fr.md) | French | fr-fr |
| [es.md](es.md) | Spanish | es-es |
| [pt-BR.md](pt-BR.md) | Portuguese (Brazil) | pt-br |
| [it.md](it.md) | Italian | it-it |
| [tr.md](tr.md) | Turkish | tr-tr |
| [pl.md](pl.md) | Polish | pl-pl |

Search terms are written the way people search in that language, not
translated word for word. Each language gets its own 7.

Screenshots and the trailer can stay the same for every language.
